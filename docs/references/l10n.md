# Flutter l10n (ARB → AppLocalizations)

Feeling Palette는 한국어 마스터 + 영어 보조.

## 파일

```
l10n.yaml                       # 설정
lib/l10n/
  app_ko.arb                    # 마스터 (template-arb-file)
  app_en.arb                    # 영어
  app_localizations.dart        # generated
  app_localizations_ko.dart     # generated
  app_localizations_en.dart     # generated
```

생성 파일은 **손편집 금지** (PreToolUse hook).

## `l10n.yaml` (예)

```yaml
arb-dir: lib/l10n
template-arb-file: app_ko.arb
output-localization-file: app_localizations.dart
synthetic-package: false
output-dir: lib/l10n
```

## ARB 항목 추가

```json
// app_ko.arb
{
  "@@locale": "ko",
  "diaryEmptyState": "오늘의 감정을 기록해 보세요",
  "@diaryEmptyState": { "description": "Home 화면 빈 상태 메시지" }
}
```

```json
// app_en.arb
{
  "@@locale": "en",
  "diaryEmptyState": "Write today's feeling"
}
```

추가 후:

```bash
flutter gen-l10n
# 또는 flutter run / build가 자동으로 호출
```

## 위젯에서 사용

```dart
import 'package:feeling_palette/l10n/app_localizations.dart';

final l = AppLocalizations.of(context)!;
Text(l.diaryEmptyState);
```

## 백엔드에 locale 전달

`lib/services/api_locale.dart` 헬퍼 사용 — `Localizations.localeOf(context)`를
서버가 인식하는 `ko`/`en` 문자열로 매핑.

```dart
final apiLocale = ApiLocale.from(context); // 'ko' | 'en'
```

## 규칙

- 사용자에게 노출되는 모든 문자열은 ARB 키. 하드코딩된 한글/영문 금지.
- 새 키는 ko 먼저 (마스터), en 동기화.
- description은 ko ARB에만 (`@key`로). 번역가/에이전트가 의미 파악할 수
  있도록.
- placeholder 사용:
  ```json
  "diaryCount": "{count}개의 일기",
  "@diaryCount": {
    "placeholders": { "count": { "type": "int" } }
  }
  ```

## 관련

- `lib/services/api_locale.dart`
- 백엔드는 `ko`/`en`만 인식 — 다른 로케일은 ko fallback (확인 필요).
