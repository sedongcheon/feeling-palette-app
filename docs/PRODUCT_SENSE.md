# Product sense

UX/톤에 대한 판단이 스펙에 명시되지 않았을 때 에이전트가 따르는 기본값.

## Voice (말투)

- **직접적으로**. 버튼은 행위를 적는다: "일기 저장", "감정 분석" — "확인"
  같은 추상어 금지.
- **마케팅 톤 금지**. 빈 상태(empty state)는 "지금 무엇을 하면 되는지"를
  안내한다 — 기능 자랑이 아님.
- **에러 코드는 영문 식별자, 사용자 메시지는 현지화**. `AppLocalizations`
  키 사용; 하드코딩 문자열 금지. ko 마스터, en 동기화.
- **존댓말, 차분한 어조**. 감정일기 앱이므로 명령조/광고조 피한다.
  ("일기를 작성해 보세요" O / "지금 바로 적자!" X)

## Defaults (기본 동작)

- **Save first, confirm later**. 일기 작성은 입력 도중에도 임시 저장
  (`onChanged` 디바운스). 명시적 "삭제" 같은 비가역 작업만 확인 다이얼로그.
- **Optimistic UI**. provider/notifier에서 로컬 상태를 먼저 갱신, 서버
  응답으로 reconcile, 실패 시 Snackbar로 롤백.
- **Loading은 필수**. spinner만으로는 부족 — 스켈레톤 또는 inline 메시지.
  3초 이상 걸리는 작업은 progress 표시.
- **에러 메시지는 다음 행동을 제시**. "네트워크 오류"가 아니라 "연결을
  확인하고 다시 시도하세요" + retry 버튼.

## 금지 패턴

- Snackbar/Toast **만으로** 결과 표시 (사라짐 — inline 상태와 병기).
- 한 화면이면 충분한 일을 다단계 wizard로.
- tooltip 없는 비활성 버튼 — 왜 비활성인지 적는다.
- 10개 넘는 항목이 있는 설정 페이지에 검색 없음.
- 라우트 간 상태를 `setState`로 공유.
- 무한 스크롤 + pull-to-refresh 동시 — 하나만.
- 단일 색상 신호 (색약 대응 — 아이콘/텍스트 병기).

## 광고 UX

- 전면 광고는 사용자 액션 사이에만 (작성 후 저장 직후 X — 마찰).
- 보상형 광고는 명시적 "광고 보고 잠금 해제" 버튼 + 보상 미리보기.
- 프리미엄 사용자(`PremiumService.isPro`)에게는 광고 일체 노출 금지.
- 광고 로드 실패 시 자리표시 박스 금지 — 자연스럽게 흐름 진행.

## IAP UX

- 프리미엄 가격 표시: `ProductDetails.price` (Apple/Google가 현지 통화 자동
  처리). 직접 USD/KRW 변환 금지.
- 구매 복원(Restore) 버튼은 설정 화면에서 *항상* 접근 가능.
- 구매 실패는 사유별로 메시지 분기:
  - 사용자 취소 → 메시지 안 띄움
  - 결제 거절 / 카드 문제 → "결제 정보를 확인하세요"
  - 네트워크 → "연결 후 다시 시도하세요"

## 지연 예산 (Latency budget)

- p95 nav → 콘텐츠 표시: **300ms**
- p95 mutation → 낙관적 ack: **0ms** (로컬 먼저)
- p99 mutation → 서버 confirm: **1s**
- 감정 분석 호출: **3s p95** (서버 모델 추론 포함)

## 의심스러울 때

> 처음 앱을 여는 사용자가 5초 안에, 글을 읽지 않고도 다음 단계를 알 수
> 있는가?

NO면 단순화.

## Feeling Palette만의 톤

- 감정/심리 키워드는 *진단조* 금지: "당신은 우울합니다" X →
  "오늘 일기에서 슬픔 키워드가 자주 보였어요" O.
- 통계 화면은 *데이터로 자극하지 않는다*. "이번 주 부정 감정 비율
  60%"보다 "이번 주는 평소보다 차분한 단어가 많았어요" 같은 톤.
- "AI"라는 단어를 UI에 자주 노출하지 않는다 — 분석 결과 자체에 집중.
